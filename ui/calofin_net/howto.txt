# works, step by step where it has a real sequence of prompts, or
# in a couple of sentences where it does not (a scan-only
# companion, a DCL-form tool, a cover-sheet wrapper). Editorial
# text, hand-written, like blurbs.txt beside it -- the numbered
# steps for most commands were drawn from that command's own
# prompts in lisp/ rather than invented, then hand-checked.
#
# Read by tools/gen_ui_data.py, which writes
# ui/calofin_net/Generated/CommandCatalog.g.vb, and copied into
# lzp:*howto* in lisp/lazpanel/LAZPANEL.lsp -- tests/test_lazpanel.py
# holds the two to each other word for word, the same contract
# blurbs.txt already keeps against lzp:*blurbs*.
#
# One block per command:
#     == COMMAND ==
#     line
#     line

== CLEARDIM ==
Select the dimensions to clear (or Enter for the whole drawing). Each one's text is slid along its own track -- the dimension line, the angular arc, the radial line, the leader -- until it clears the geometry it measures; text that already reads clearly is left exactly where it is. Text only ever slides along its track, never off it.

== CLEARDIMSCAN ==

== DIMARCCHECK ==
Alias of CHECK. Select what to audit; it checks that every dimension's definition points land on real geometry or on a shared ANCHOR -- a point two or more dimensions measure to, which counts as an object in its own right. A dimension with a stray point gets a construction line drawn through its two points, the stray point snapped onto the nearest object or anchor, and its color changed so the fix is visible.

Highlight the spa drawing together with its "Spa Cover Details" block; runs SPACHECK's full set of audits -- built from what SPA itself draws, so a SPA-produced drawing passes and a hand-edited one shows exactly where it drifted -- but read-only, as one scan instead of a guided walk.

== SPACOVCREATE ==
Offsets a selected spa outline into its cover and hinges it to the taper.
What it asks, in order:
 1. Select objects
 2. Cover offset past the spa
 3. Select the block that gives the taper
 4. Taper (3-2, 4-2, 4-3, 5-3, 5-4, 3-3, 1-3/8)

== SQUAREUP ==
Turns a highlighted drawing until its perimeter's longest wall (or span) is horizontal.
What it asks, in order:
 1. Select objects
 2. What should end up horizontal?
 3. Turn the highlighted objects anyway?

== OSR ==
Puts your running object snaps back to the preset you chose - one word, no questions.
Choose the preset once in Options (LAZSET): the Object snaps box ticks the same modes as AutoCAD's Drafting Settings, plus Object Snap On, and Use current takes whatever the drawing has ticked now. CALSET - Osnaps does the same at the command line.
With no preset saved, OSR puts back Endpoint, Midpoint, Center, Node, Quadrant, Intersection and Perpendicular, Object Snap on.
