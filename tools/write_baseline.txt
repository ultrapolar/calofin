# Writes whose answer nobody reads, followed by a count or a claim, that
# a person has READ and found fine (tools/check_writes.py, rule W2).
# One line per site:
#
#   file|defun|the write as written|needs=TOKEN[@DEFUN][,TOKEN[@DEFUN]...]|why
#
# The write is matched by its tool, its defun and its text, not its line,
# so an edit elsewhere in the file does not stale it, and one line covers
# the tool's lisp/ file, its shared/ twin and its dated releases/ copy.
# A write longer than 80 characters carries a hash of the rest.
#
# NEEDS names what makes the site honest, as it is written in the code:
# each TOKEN must still be in the text of DEFUN (the site's own defun when
# none is named), in the same file, comments not counting.  A line whose
# token has gone no longer excuses its site and is reported stale: the
# reason it was written is not in the tree any more.  Every line has one.
#
# A line whose write has gone, been reworded or started to be looked at
# is reported stale too.  There is no --update-baseline on purpose: a
# real defect is fixed, not written down here, and a bulk accept is how
# one would get in.  Rule W1 takes no baseline -- a layer helper has no
# reason to leave a lock on.
